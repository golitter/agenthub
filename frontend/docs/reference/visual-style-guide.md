# AgentHub Visual Style Guide

> Dark Runtime Workspace — 墨青 · 克制 · 可扫视 · 工具感
> 本文档以暗色主题为主描述设计规范。亮色主题使用相同的 token 架构，色值见 color-palette.md。

## 定位

AgentHub 不是营销页，也不是普通 AI 聊天软件，而是 AI Runtime Workspace。用户在这里调度 Agent、看 Diff、看 Logs、看 Preview、管理 Skills、观察多 Agent 协作流。视觉风格必须传递"安静的开发者工作台"气质，而非"聊天机器人"或"通用后台"。

参考产品气质（不是照搬 UI）：

| 产品           | 借鉴什么                     |
| -------------- | ---------------------------- |
| Linear         | 克制暗色、精确间距、极简交互 |
| Cursor         | IDE 氛围、代码为核心         |
| Vercel         | 部署状态可视化、干净面板     |
| Slack          | 对话流的 IM 节奏感           |
| GitHub Actions | Event Timeline 的运行时感    |

## 一、色彩体系

### 1.1 背景色阶

层级主要靠墨青灰阶区分，辅以非常轻的边框和阴影。背景之间差值要足够分辨，但不能出现纯黑断层。

| 用途                             | 色值      | 变量名                         |
| -------------------------------- | --------- | ------------------------------ |
| 主画布（中栏聊天区 / SkillsHub） | `#0B1110` | `--bg-canvas` / `--background` |
| 侧边栏                           | `#101715` | `--bg-sidebar` / `--sidebar`   |
| 卡片/面板                        | `#141C1A` | `--bg-card` / `--card`         |
| 悬停态/提升态                    | `#1E2A27` | `--bg-hover` / `--accent`      |
| 按下态/最浅提升                  | `#273531` | `--bg-active`                  |

聊天区和 SkillsHub 页可使用 `.chat-canvas` 的 22px 点阵微纹理，纹理由 `color-mix(in srgb, var(--foreground) 7%, transparent)` 生成，只用于打破大面积空黑，不作为装饰图案。

### 1.2 文字色阶

| 用途                       | 色值      | 变量名                            |
| -------------------------- | --------- | --------------------------------- |
| 主要文字（标题、正文）     | `#E6EFEC` | `--text-primary` / `--foreground` |
| 次要文字（时间戳、描述）   | `#92A09C` | `--text-secondary`                |
| 辅助文字（占位符、禁用态） | `#697773` | `--text-tertiary`                 |

### 1.3 品牌色

全局只有一个品牌色，极度克制地使用——仅出现在选中态、发送按钮、当前会话标记、焦点环。

| 用途     | 色值                       | 变量名                        |
| -------- | -------------------------- | ----------------------------- |
| 品牌主色 | `#5EEAD4`                  | `--color-brand` / `--primary` |
| 品牌浅底 | `rgba(94, 234, 212, 0.10)` | `--primary-soft`              |
| 品牌边框 | `rgba(94, 234, 212, 0.20)` | `--primary-border`            |

### 1.4 Agent 标识色

不算装饰色，是功能色——用于区分 Agent 身份。只用在 Agent 头像和消息左侧色条。

| Agent        | 色值      | 变量名                 |
| ------------ | --------- | ---------------------- |
| Claude Code  | `#DA7756` | `--agent-claude`       |
| OpenCode     | `#10B981` | `--agent-opencode`     |
| Orchestrator | `#EAB308` | `--agent-orchestrator` |
| Codex        | `#5EEAD4` | `--agent-codex`        |
| Pi           | `#C4B5FD` | `--agent-pi`           |

### 1.5 语义色

| 状态 | 色值      | 变量名                                |
| ---- | --------- | ------------------------------------- |
| 成功 | `#4ADE80` | `--color-success`                     |
| 警告 | `#FBBF24` | `--color-warning`                     |
| 错误 | `#F97066` | `--color-error`（即 `--destructive`） |

### 1.6 色彩禁令

- 不使用紫蓝 AI 渐变，不使用霓虹外发光
- `radial-gradient` 只允许用于 `.chat-canvas` 这种低对比微纹理
- `backdrop-blur` 只允许用于固定遮罩/弹层，不用在滚动容器
- 不使用纯白文字（`#FFFFFF`），正文用 `#E6EFEC`
- 不使用纯黑文字（`#000000`）
- 不在 UI 框架上使用 Agent 标识色，它们只标识身份

## 二、字体系统

### 2.1 字体选择

| 用途     | 字体       | 理由                                                           |
| -------- | ---------- | -------------------------------------------------------------- |
| UI 文字  | Geist Sans | Vercel 出品，为开发者工具设计；比 Inter 更紧凑，适合高密度界面 |
| 代码文字 | Geist Mono | 与 Geist Sans 配套，UI 文字和代码视觉统一                      |

### 2.2 字号体系

| 用途     | 字号 | 字重           | 行高 | 场景                   |
| -------- | ---- | -------------- | ---- | ---------------------- |
| 页面标题 | 20px | 600 (SemiBold) | 1.3  | Task 名称              |
| 区块标题 | 14px | 600            | 1.4  | 面板标题、卡片标题     |
| 正文     | 14px | 400 (Regular)  | 1.6  | 聊天消息、描述文字     |
| 辅助文字 | 12px | 400            | 1.5  | 时间戳、标签、次要信息 |
| 代码     | 13px | 400            | 1.65 | 代码块、终端输出       |
| 微标注   | 11px | 500 (Medium)   | 1.4  | Badge、Agent 状态标签  |

### 2.3 字间距

- UI 文字：`0`（避免中文和小字号控件发紧）
- 代码文字：`0`（等宽默认间距）
- 大写标签（Badge）：`+0.05em`（拉开间距，提升可读性）

## 三、圆角

| 元素       | 圆角    | 说明                             |
| ---------- | ------- | -------------------------------- |
| 按钮       | 8-10px  | 工具感，但保留触感               |
| 输入框     | 10-12px | 与搜索/消息输入一致              |
| 卡片       | 12-14px | SkillsHub、消息卡片等内容容器    |
| 面板       | 14-16px | 大面板、弹层                     |
| Agent 头像 | 7-9px   | 圆角方形，区别于传统圆形聊天头像 |
| 用户头像   | 10px    | 圆角方形，保持工作台一致性       |
| Badge/标签 | 4-6px   | 避免过度胶囊化                   |

### 圆角禁令

- 不使用 20px 以上的大圆角
- 不使用 `rounded-full` 用在按钮或卡片上；状态点可用 `rounded-full`
- 不做 iOS 风格的大圆角

---

## 四、边框

- 通用边框：`1px solid rgba(255, 255, 255, 0.06)`
- 分割线：`1px solid rgba(255, 255, 255, 0.04)`（比边框更淡）
- 焦点环：`2px solid var(--color-brand)` + `2px offset`
- 不用实色边框（如 `#333`）

---

## 五、阴影与深度

### 核心原则：轻阴影只服务层级

深度主要靠背景色差表达，但内容卡片、头像、弹层可以使用低透明阴影，避免大面积深色页面变成扁平黑块。

| 层级           | 色值      | 场景     |
| -------------- | --------- | -------- |
| 层级 0（最底） | `#0B1110` | 画布     |
| 层级 1         | `#101715` | 侧边栏   |
| 层级 2         | `#141C1A` | 卡片     |
| 层级 3（最高） | `#1E2A27` | 悬浮卡片 |

常用阴影：

```css
/* 卡片 / 消息块 */
box-shadow: 0 12px 32px rgba(0, 0, 0, 0.08);

/* 弹层 */
box-shadow: var(--shadow-popup); /* dark: 0 18px 52px rgba(0,0,0,0.42) */
```

## 六、间距系统

基础单位：**4px**

### 间距档位

| 名称 | 值   | 场景                         |
| ---- | ---- | ---------------------------- |
| xs   | 4px  | 图标与文字间距、内联元素间距 |
| sm   | 8px  | 紧凑元素间距                 |
| md   | 12px | 列表项间距                   |
| lg   | 16px | 区块内间距（卡片 padding）   |
| xl   | 24px | 区块间间距                   |
| 2xl  | 32px | 大区块间距                   |
| 3xl  | 48px | 页面级间距（极少使用）       |

### 组件内部 padding

| 组件         | padding   |
| ------------ | --------- |
| 按钮（小）   | 8px 16px  |
| 按钮（标准） | 10px 20px |
| 卡片         | 16px      |
| 输入框       | 10px 14px |
| 面板         | 16-20px   |
| 列表项       | 10px 12px |

### 密度原则

这是开发者工具，间距紧凑但不能压扁可读性。聊天内容使用中心轨道，页面型工具（如 SkillsHub）使用 `max-w-[88rem]` 主容器 + 右侧摘要栏，避免宽屏右侧空黑。

## 七、图标

选择：**Lucide React**（通过 `strokeWidth={1.25}` 模拟细线视觉）

理由：

- 与 shadcn/ui 深度集成，组件库内置 Lucide
- 生态成熟，图标覆盖面广
- 通过 `strokeWidth={1.25}` 可模拟 Phosphor Light 的细线风格，兼顾精致感
- 与 development-strategy.md 保持一致，避免文档矛盾

不选：

- FontAwesome — 太重，不适合精致 UI
- Material Icons — 圆润风格不匹配

## 八、动效

### 哲学

存在感极弱，几乎感觉不到，但没有就会觉得"卡"。

### 时长

| 场景                     | 时长  | 缓动     |
| ------------------------ | ----- | -------- |
| 微交互（hover、focus）   | 120ms | ease-out |
| 状态切换（展开/折叠）    | 200ms | ease-out |
| 面板出入（右侧面板滑入） | 250ms | ease-out |
| 页面级过渡               | 300ms | ease-out |

### 允许的动效

- hover 背景色变化（120ms ease-out）
- active 轻微 `scale(0.98)` / `scale(0.995)`
- 面板滑入/滑出（250ms ease-out，`transform: translateX`）
- Agent 思考指示器（三点跳动）
- 状态灯颜色变化（200ms ease-out）
- 新消息入场（底部滑入，300ms ease-out，轻微透明度渐变）

### 禁止的动效

- 毛玻璃/模糊动画
- 渐变流光
- 粒子效果
- 3D 旋转
- 大幅位移动画
- 弹簧物理动画（overshoot/bounce）
- 骨架屏强闪光扫描效果；允许低对比 `animate-pulse`

### 性能约束

- 只动画 `transform` 和 `opacity`，不动画 `top`、`left`、`width`、`height`
- `backdrop-blur` 只用于固定/粘性元素（导航栏、遮罩层），不用在滚动容器上

## 九、Agent 身份系统

每个 Agent 拥有统一的视觉标识格式：

```
身份 = 图标 + 标识色 + 头像形状 + 状态灯
```

### 头像

- 形状：圆角方形（8px 圆角）— 区别于用户的圆形头像，暗示"这是工具/服务"
- 尺寸：32px（消息流中）、24px（侧边栏紧凑模式）
- 外层：`rounded-[9px] border border-border/70 bg-card p-0.5`
- 阴影：`0 8px 20px rgba(0,0,0,0.16)`，不使用 Agent 色外发光
- 内层：`rounded-[7px]`，有图片时透明底，无图片时使用 Agent 标识色低饱和底

### 状态灯

头像右下角 5px 圆点：

| 状态   | 颜色           | 动效                              |
| ------ | -------------- | --------------------------------- |
| 就绪   | 绿色 `#4ADE80` | 脉冲（2s 循环，透明度 0.6→1→0.6） |
| 执行中 | 黄色 `#FBBF24` | 旋转（1.5s 循环）                 |
| 离线   | 灰色 `#697773` | 无                                |
| 出错   | 红色 `#F97066` | 无                                |

### Agent 身份标签

Agent 消息头部显示名称 + `agentType` 小标签。标签文字使用 Agent 标识色，背景为 `${agentColor}1A`，避免在消息容器上增加过多色条。

## 十、组件视觉规范

### 10.1 消息气泡

**用户消息**：

- 右对齐
- 背景：`bg-primary/15`（品牌色 15% 透明度）
- 边框：`1px solid primary/25`
- 圆角：`15px`，发送端角为 `4px`（`rounded-br-[4px]`）
- Padding：`px-4 py-2.5`（16px / 10px），短消息必须紧凑，不能像按钮块
- 最大宽度：`min(86%, 36rem)`，`sm` 断点收窄至 `min(74%, 36rem)`
- 右侧紧贴管理员头像（28px 圆角方形 `rounded-[10px]`，加载失败回退 `/favicon.svg`）

**Agent 消息**：

- 左对齐
- 内容区分两种变体：
  - **结构化**（含 blocks）：`bg-card/80` + `border-border/60` + 圆角 `12px` + 阴影
  - **纯文本**：`bg-card/25` + 左侧 `border-l-2 border-primary/30` + 圆角 `rounded-r-[10px]`
- 最大宽度：纯文本 `min(100%, 38rem)`，结构化/长消息 `min(100%, 46rem)`

**系统消息**（Orchestrator 调度、状态变更）：

- 居中
- 文字：`var(--text-secondary)` `#92A09C`
- 字号：12px
- 无气泡背景

### 10.2 代码块

- 背景：`#0E1715`（比画布更深一级）
- 字体：Geist Mono，13px
- 行号：左侧独立列，`var(--text-tertiary)` `#697773`
- 语法高亮：Tokyo Night 主题色系
- 圆角：8px
- 内边距：16px

### 10.3 Diff 卡片

- 旧代码区域：`rgba(249, 112, 102, 0.08)` 红色调背景
- 新代码区域：`rgba(74, 222, 128, 0.08)` 绿色调背景
- 删除行左侧 `-` 标记，新增行左侧 `+` 标记
- 头部：变更摘要（文件数、+/- 行数）+ Split/Unified 视图切换 + 定稿状态 Badge
- 操作按钮：「接受变更」/「拒绝变更」（非定稿时可用），另支持切换 CodeMirror 编辑

### 10.4 输入区

- 背景：`var(--bg-card)` `#141C1A`
- 边框：`1px solid rgba(255, 255, 255, 0.06)`
- 焦点态边框：`1px solid var(--color-brand)`
- 圆角：8px
- 最小高度：48px，支持多行展开
- 占位符文字：`var(--text-tertiary)` `#697773`

### 10.5 侧边栏列表项

- 默认背景：透明
- Hover 背景：`var(--bg-hover)` `#1E2A27`
- 选中态：`border-primary-border` + `bg-primary-soft`
- 内边距：10px 12px

### 10.6 SkillsHub

- 页面容器：使用 `.chat-canvas`，避免大面积空黑。
- Header：铺满页面宽度，内部 `max-w-[88rem]` 对齐主体。
- 主体：`xl:grid-cols-[minmax(0,1fr)_18rem]`，左侧技能网格，右侧状态摘要栏。
- 技能卡：`md:grid-cols-2`，卡片 `min-h-[8rem] rounded-[14px] border-border/70 bg-card/80`。
- 加载态：用 4 个骨架卡片替代一行 loading 文本。

## 十一、总结

```
Dark Utilitarian — 三原则

1. 层级靠墨青色阶 + 轻边框 + 低透明阴影
   背景 5 级灰阶，从 #0B1110 到 #273531

2. 色彩靠功能，不靠装饰
   全局 1 个品牌色 + 5 个 Agent 色 + 3 个语义色

3. 动效靠存在，不靠表现
   120-300ms ease-out，只做状态过渡和轻触感
```

它看起来像 Linear 的暗色面板，读起来像 JetBrains IDE 的代码区，用起来像 Slack 的对话流。它是一个安静的、精密的控制台。
